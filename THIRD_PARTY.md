# Third-party components

The [repository license](LICENSE) covers Ego2Flow's orchestration and evaluation code. Third-party models, datasets and simulation software remain subject to their respective licenses. Argoverse 2 terms apply to the derived scene data.

| Component | Use |
| --- | --- |
| [CARLA 0.9.16](https://github.com/carla-simulator/carla/releases/tag/0.9.16) | Simulation, sensors, Traffic Manager, BasicAgent, routing and PID control |
| [Argoverse 2](https://www.argoverse.org/av2.html) | Front-camera calibration for OneVL and Alpamayo |
| [SUMO v1_23_1 Energy](https://raw.githubusercontent.com/eclipse-sumo/sumo/v1_23_1/src/utils/emissions/HelpersEnergy.cpp) | Longitudinal work equations for the trajectory energy estimate |
| [FASTSim 3.1.0](https://github.com/NatLabRockies/fastsim/blob/v3.1.0/fastsim-core/resources/vehicles/2022%20Tesla%20Model%203%20RWD%20thrml.yaml) | Model 3 RWD reference parameters |
| [IDM](https://traffic-simulation.de/info/info_IDM.html) | Longitudinal following equation |
| [LEAD cvpr2026](https://github.com/kesai-labs/lead/tree/cvpr2026) | Sensor preprocessing, model, planning and controllers |
| [Bench2DriveZoo](https://github.com/Thinklab-SJTU/Bench2DriveZoo) | UniAD model, inference pipeline and camera calibration |
| [OneVL](https://github.com/xiaomi-research/onevl) | Impromptu trajectory model |
| [Alpamayo 1.5](https://github.com/NVlabs/alpamayo1.5) | Trajectory model and inference API |
